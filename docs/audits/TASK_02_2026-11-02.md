## 2. 最小临时目录方案

`tests/conftest.py:9` 的 pytest_configure 在没有显式 basetemp 时，在仓库 `.pytest_cache/ppa-tmp` 下用 tempfile.mkdtemp 独占分配全新 session 目录。pytest 只管理这个刚生成的目录，不接触其他会话、用户库或源码。不使用固定共享目录、不依赖系统 Temp，也不改变全局 TMP/TEMP；适用于 pytest、IDE、verify 和 CI 的同一测试入口。

配置拒绝缓存路径重定向；显式 `--basetemp` 保持 pytest 原语义，由调用者保证其安全。目录保留供诊断，避免启动时清理并发会话；代价是缓存会增长，需人工确认会话结束后清理。未对 Windows ACL 做修复。详见 [工程基线](../ENGINEERING_BASELINE.md)。

安全回归不是只检查配置值：独立小测试工程连续运行两次 pytest，断言各自使用不同目录且第一次的 sentinel 仍存在。没有删除、跳过或弱化原来的 68 个测试。

# 安全和部署范围

**这是本地教学/作品集演示，不具备公网生产部署条件。**

- 只绑定 `127.0.0.1`；Docker 使用 `-p 127.0.0.1:8000:8000`。不支持多用户授权隔离，`thread_id` 不是用户身份标识。
- `PPA_API_TOKEN` 仅为共享演示口令，不能替代 OAuth、用户权限、操作审计和资源级访问控制。
- `.env` 在 `.gitignore` 中，不要提交 API Key。CI 从不调用真实模型。
- 千问 Agent 默认关闭；启用后只能读取模拟数据，不能调用真实日历/任务服务；当用户关闭服务时没有持续执行后台作业。
- 只有用户显式点击批准后，才进入 M4 可靠任务写入。建议和业务数据在 SQLite 的**不同文件**中保存 Checkpoints。
- 单进程内部的 per-thread lock 不提供跨进程互斥；真实多实例需要数据库锁、租约或队列。
- 当前部分输入验证/SQL 幂等记录用于演示。生产系统仍需请求限流、跨租户隔离、指标告警、加密和数据生命周期管理。
- 所谓“幂等”，限于同一业务操作 ID 对当前本地 SQLite 服务的副作用去重；它不是跨第三方 API 的 Exactly-Once 保证。

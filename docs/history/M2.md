# M2 Incremental Overlay

This is an **incremental addition** to the same personal-productivity-agent repository.
Do not replace M1. Ensure your `calendar.py` already has the M1 implementation.

Copy `src/` and `tests/` contents over existing matching directories.

Add to the existing `[project].dependencies` list in `pyproject.toml`:

```toml
"langchain-openai>=1.0,<2.0",
"pydantic>=2.8,<3.0",
```

Update environment via `python -m pip install -e ".[dev]"`.

Offline tests:

```powershell
python -m pytest -q tests/test_m2_intent.py tests/test_m2_graph.py
```

Live model API demo (requires OpenAI API key and incurs usage charges):

```powershell
$env:OPENAI_API_KEY="YOUR_KEY"  # only locally; never commit credentials
python -m productivity_agent.demo_m2
```

Important: the live LLM may return different semantic interpretations. Structured output constrains the shape but does not guarantee correct interpretations. Fake-extractor tests are deterministic; the model API demo is not. The demo's reference time is frozen for repeatability. Do not use this as a production calendar backend; no event is created and no real calendar is queried.

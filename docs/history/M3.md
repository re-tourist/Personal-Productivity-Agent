# M3 incremental overlay: Qwen + LangGraph Tool Calling

**Copy only the overlay's `src/` and `tests/` folders into your existing PPA repository**. This is NOT a replacement project: M1 `calendar.py` and M2 `intent.py`/`natural_language.py` remain unchanged. `demo_m2.py` is intentionally replaced to switch from OpenAI to Qwen.

## Dependencies

Add the following to the existing `[project].dependencies` array in `pyproject.toml` if missing:

```toml
"langchain-openai>=1.0,<2.0",
"pydantic>=2.8,<3.0",
"python-dotenv>=1.0,<2.0",
```

The project already depends on `langgraph>=1.0,<2.0`. In your `conda activate ppa` terminal:

```powershell
python -m pip install -e ".[dev]"
```

## Configure Qwen

Copy `.env.example.m3` to `.env` in the repository root (merge with existing .env if present). Set `DASHSCOPE_API_KEY` locally, NEVER in a git-tracked file.

The sample Beijing endpoint is a currently supported legacy address. Alibaba Cloud recommends a workspace-specific endpoint; set `DASHSCOPE_BASE_URL` to a matching region and workspace, e.g. `https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/compatible-mode/v1` (replace placeholder). Your key and endpoint MUST share the same region.

Default model: `qwen3.7-flash`, `enable_thinking=False`, `max_tokens=600`, `max_model_calls=4`. Charges are possible for live demos. The environment is **not** automatically upgraded to Plus/Max.


## Live demonstration (Qwen API calls; consumes tokens)

```powershell
python -m productivity_agent.demo_m3
python -m productivity_agent.demo_m3 --message "请检查明天下午15点到16点是否能安排一小时组会"
python -m productivity_agent.demo_m2
```

In-memory-only mock task writing, expressly opted in:

```powershell
python -m productivity_agent.demo_m3 --allow-mock-writes --message "请创建明天下午两点半提醒我准备组会的待办任务"
```

**Important limitations:** No real calendar or task account is connected; memory contents reset on program restart. M3 does not implement durable storage, idempotency, user authentication, approval workflows, or retries (those belong to M4+). The graph has a small maximum number of model calls, but external provider-side charge may vary. Offline tests use a fake model and need no key.

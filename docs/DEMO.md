# 两分钟演示脚本（实习面试）

1. 浏览器打开 `http://127.0.0.1:8000/app`，说明工程使用 **LangGraph 状态流转 + FastAPI API + SQLite Checkpointer + 业务幂等事务**。
2. 在“日程冲突检查”输入组会时间，点击“填入冲突示例”并执行；检查它推荐半小时步长下的首个不冲突时间，演示 SSE 进度。
3. 在“待办任务与人工审批”中创建草稿，展示返回 `thread_id` 和等待确认状态。在另一终端重启服务，使用同一 Thread ID 查询状态，再点击“批准”。
4. 观察任务列表中出现一条记录。第二次批准同一 Thread 会得到 `409`，说明服务拒绝重复审批。说明底层 M4 还通过**幂等键、唯一索引、数据库事务**避免外部重试造成重复任务。
5. 显示 `reports/m7-offline-evaluation.json`：说明 10 个离线业务场景和独立 pytest 测试，不把这些结果包装成真实 LLM Task Success Rate。
6. 如果已开启千问，可以演示自然语言意图抽取、Tool Calling 及模型预算。关闭时界面显示 `503` 是刻意的，避免隐式调用付费 API。

**面试重点陈述**：State 是图执行上下文；Checkpointer 用于恢复执行；业务数据库与幂等键保护业务副作用。HTTP 请求、LangGraph Thread 和真实任务记录彼此分离。失去网络响应不等于服务端没有提交，不能盲目重试写入。

**不要声称**：实现真实日历对接、生产级 Exactly-Once、gRPC 服务端、多租户权限，或已经完成千问在线评测。
